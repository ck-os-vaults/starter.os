# evidence research

Use when current external evidence materially affects the answer.

1. Define the decision and freshness requirement.
2. Prefer primary and authoritative sources.
3. Separate verified facts, source claims, and inference.
4. Compare dates and event dates for changing information.
5. Cite the source nearest each supported claim.
6. End with the decision-relevant conclusion, uncertainty, and next action.

Repository truth comes from the repository, not web research.
