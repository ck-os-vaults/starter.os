# conversations

**Bottom line:** Optional permanent source collection for verbatim owner interviews, conversations, and transcripts. Agent-written summaries belong in `log/sessions/` instead.

**When to read this:** Read only when the owner's original words materially matter and curated context is insufficient.

## rules

- Preserve the owner's words; do not silently polish or rewrite them.
- Use `YYYY-MM-DD-topic.md` names and a short routing summary before long transcripts.
- Keep sensitive third-party conversations out unless the owner has the right and a clear reason to store them.
- Store large audio or video outside Git in an owner-approved media location; keep a transcript or pointer here only when privacy and backup rules are settled.
- Never bulk-import recordings during initial setup. Inventory and classify them first.
