# morning brief

**Bottom line:** Prepare the owner for the day from verified commitments, current priorities, and meaningful project changes, then return the owner's short check-in to the persistent Chief of Staff home base.

## purpose

Create a small owner-fit start-of-day/work-block plan that makes the next action obvious.

## trigger

Morning, start of work, an owner request for the day plan, or an accepted recurring Morning Brief.

## steps

1. Check only authorized sources that actually exist: current project status, prior carry-forward, task system, calendar, and the week ahead.
2. Use `task-reconciliation.md` to include only material cross-project changes since the last checkpoint.
3. Separate fixed commitments from flexible work and note any conflict or unverified source plainly.
4. Select no more priorities than the owner approved and give each one concrete next action.
5. End with a few short questions about energy, personal constraints, new tasks, or changed direction. Distill the answers back into the persistent Chief of Staff home base and the correct durable owner file only when warranted.

## outputs

- plain-language front-page brief and itinerary
- week-ahead watch items
- concise owner questions
- optional `life/records/daily/YYYY-MM-DD.md`

## optional scheduled recipe

When the owner accepts a recurring `Morning Brief`, use the verified timezone and an owner-chosen time. Attach the routine to the persistent Chief of Staff home base when the scheduler supports that destination. Update an equivalent routine instead of creating another one.

Verify name, schedule, timezone, destination, instructions, calendar and task access, project access, runtime, active status, and first eligible run. Missing source access is a named limitation, not permission to fabricate an itinerary.

## boundaries

- Do not write a motivational essay.
- Do not overload low-capacity days.
- Do not fabricate calendar or task information.
- Do not create calendar events, reminders, tasks, or durable records unless the owner has authorized that action.
