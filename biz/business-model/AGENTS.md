# business model agent overlay

Read `../../os/AGENTS.md` first and follow the boot chain in `../../os/me.md`.

This is the generic model for the first real business. Read its `readme.md`, `status.md`, and `knowledge-map.md` only to understand the structure. Do not add owner context here. When a business is confirmed, copy this model into `../<business>/` with `ruby setup/add-business.rb <lowercase-kebab-name>` from the vault root.

Each real business owns its documents and implementation source in one repository. Never create a nested repository or submodule. Shared rules come from `../../os/`; personal context comes from `../../life/` only when the task genuinely needs it.
