# browser use

Use a native browser inside the active agent product for interactive website work when available. Prefer a purpose-built connector, API, or CLI for structured retrieval. Use an external browser only when the owner requests it or a verified capability gap requires it.

Treat sign-in, submission, purchase, posting, and account changes as explicit approval boundaries. Use only the owner's authorized credential path and never expose or retain secret values.
