# now — current state

**Bottom line:** A small current-state snapshot: the owner's active priorities, open decisions, important constraints, and upcoming anchors. It is updated as life changes; it is not a diary.

**When to read this:** Read for planning, daily or weekly reviews, priority decisions, and check-ins. Do not load for unrelated technical or reference work.

## current priorities

To be drafted from the approved onboarding summary. Keep only the small number the owner can realistically hold now.

## open decisions

Record each open decision with the condition, date, or missing evidence that will resolve it. Deferred does not mean forgotten.

## important constraints

Only current constraints that materially change planning or execution.

## upcoming anchors

Important deadlines, appointments, launches, trips, or review dates. This is not a replacement for the owner's calendar.

## context routes

Point to the current status file for each active project, business, or area once those exist.
