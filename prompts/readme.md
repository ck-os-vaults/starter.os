# setup prompts

**Bottom line:** Copy-and-run prompts for interviewing the owner, building the approved system, testing it, setting up private version history, reviewing the first week, and upgrading to the current architecture.

**When to read this:** Read when choosing the next setup step from `FRIEND-SETUP-GUIDE.md`.

Run in order:

1. `01-onboarding-interview.md`
2. `02-build-approved-system.md`
3. `03-review-and-test.md`
4. `04-private-git-setup.md`
5. `05-first-week-review.md` after one week of use
6. `06-upgrade-to-current-architecture.md` once the vault is in real use and the owner wants the source system's later improvements — runs without approval gates and includes private-GitHub setup, so it also covers vaults that skipped prompt 04
