# personal journal

**Bottom line:** Optional home for the owner's reflective writing in their own words, separate from agent-written operational daily records.

**When to read this:** Read only when the owner's original reflections materially help the task or during an owner-approved distillation pass.

Journal entries use `YYYY-MM-DD.md`, `type: journal`, and `source: owner`. They do not require a summary header. Agents may reference or distill them with permission but do not rewrite the original entry.
