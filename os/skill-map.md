# skill map

**Bottom line:** Trigger table for reusable agent routines. Setup, metadata audit, and security sweep are core safeguards; other routines remain drafts until the owner's real use proves they help.

**When to read this:** Read at startup. When a task matches a trigger, open only that skill file.

| skill | trigger | output |
|---|---|---|
| [[system-setup]] | approved onboarding context | personalized, validated vault |
| [[metadata-audit]] | import, restructure, or retrieval drift | trustworthy metadata and routes |
| [[security-sweep]] | before first upload, after unknown imports, or before public work | secret/privacy findings and blockers |
| [[inbox-triage]] | raw or unclear capture exists | routed material and blockers |
| [[daily-brief]] | start of day or work block | small owner-fit plan |
| [[eod-wrap]] | end of meaningful work | durable record, verified checkpoint, next action |
| [[weekly-review]] | weekly reset | evidence-based progress, drift, and priorities |
| [[decision-log]] | owner confirms a durable choice | dated decision and reason |
| [[research-synthesis]] | source-heavy or current question | decision-ready synthesis |
| [[product-scope-review]] | product, workflow, or system idea | scope critique and next layer |
| [[read-first-code-review]] | code review or audit | evidence-backed findings |
| [[project-handoff]] | pausing meaningful work | concise continuity record |
| [[distill]] | monthly after enough log history exists | durable signal promoted with receipts |
| [[vault-maintenance]] | monthly or after structural drift | validated structure, archive proposals, backup check |
| [[drift-recovery]] | repeated restart or parallel-system urge | return to plan or justify a narrow change |

Do not activate every routine during onboarding. A supplied draft is an available method, not an obligation.
