# vault maintenance

Use for owner-approved structural cleanup or when routing has become unclear.

1. Run repository preflight for the affected repositories.
2. Inventory actual files, routes, links, Git state, and recovery coverage without changing anything.
3. Classify exact items as current, misplaced, redundant, stale, unique, untracked, or unresolved.
4. Present the smallest useful move, combine, create, and remove plan. Wait for approval before structural change or deletion.
5. Make only approved changes. Do not create archive folders as a substitute for Git history.
6. Update maps and active links, run validation, inspect the diff, and close out only the changed repositories.

Never delete unique untracked material, current truth, protected files, or anything with an active dependency.
