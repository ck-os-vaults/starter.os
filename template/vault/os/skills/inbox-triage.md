# inbox triage

## purpose

Turn raw capture into usable routed material without making capture itself difficult.

## trigger

When `life/00_inbox/` contains raw, imported, processed, or unclear personal material.

## steps

1. Read each item before changing it.
2. Choose exactly one owner and primary home using `os/vault-map.md`; business material leaves Life and enters its business repository.
3. Preserve owner meaning; summarize rather than over-edit.
4. Add only useful links and metadata.
5. Leave unclear items in the inbox with a blocker.
6. Stop and run `security-sweep.md` when an import contains credentials, recovery codes, private third-party data, or unknown exports.
7. Archive useful processed originals; never delete by default.
8. Update affected indexes and validate.

## boundaries

- Do not create new top-level folders.
- Do not turn every idea into a project.
- Do not silently rewrite owner voice.
