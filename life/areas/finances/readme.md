# finances

**Bottom line:** Generic home for personal financial administration, planning, records, and review. Add only owner-confirmed information.

**When to read this:** Read when an ongoing financial responsibility needs context beyond a one-time project or dated record.

## starting point

No accounts, balances, income, debts, taxes, goals, providers, or financial decisions are assumed here. Keep sensitive credentials outside the vault, time-bound work in `../../projects/`, and durable confirmed decisions in `../../records/decisions.md`.

Use this area only after the owner confirms that it is useful. This system records owner context; it does not provide financial advice or make financial decisions.
