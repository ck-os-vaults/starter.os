# task reconciliation

Use when meaningful decisions, status, blockers, or ownership span multiple project tasks.

1. Read only the relevant recent task summaries and project truth.
2. Keep routine project reporting in its operational home task.
3. Bring Chief only material changes that affect priorities, conflicts, authority, risk, or another project.
4. Report what changed, what is waiting, the next one to three priorities, and any owner decision required.
5. Update durable records only when authorized and only in the canonical owner.

Reconciliation connects the system; it does not duplicate every project report in Chief.
